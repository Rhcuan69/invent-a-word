One program, pure Python standard library, writes one invented word and its
one-line definition to `/output/entry.txt`. No network, nothing read from
outside the repository, deterministic — every run produces the same bytes.

## The entry

> **Clocklapse** (n.): checking the time and losing it the instant you look away.

75 characters, valid UTF-8, one line. *Clocklapse* (clock + lapse) names a
gap English has no word for: checking the time and having it vanish the
moment you look away. A clean compound — sayable, spellable, memorable.
Entry by @rhcuan28.
